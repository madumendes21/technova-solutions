# 🚀 TechNova Solutions — Portal Web Corporativo

Projeto desenvolvido para a Avaliação Somativa de Desenvolvimento Front-End (**Sprints 1 e 2**). O objetivo é construir um website institucional moderno, responsivo, acessível e 100% validado segundo os padrões do consórcio W3C para a startup **TechNova Solutions** (focada em Computação em Nuvem, Inteligência Artificial e Cibersegurança).

## 🛠️ Etapas Concluídas

### ✅ Sprint 1: Planejamento & Estrutura Semântica (HTML5)
* Criação do wireframe de planejamento visual (`wireframe.png`).
* Estruturação das 6 seções principais + Rodapé utilizando tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<aside>`, `<footer>`).
* Implementação de metadados de SEO e acessibilidade (WCAG).
* Tabela comparativa de planos com `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, `colspan` e `rowspan`.
* Formulário corporativo com `<fieldset>`, `<legend>`, `<label>` vinculados e validação nativa HTML5.
* Otimização de todas as imagens para o formato `.webp`.
